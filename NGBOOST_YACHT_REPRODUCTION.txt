Metric              Paper          Local mean   Local split SD   Local split SEM
NLL (nats/example)  0.20 +/- 0.26   0.411059344  0.262116781      0.058611094
RMSE (target units) 0.50 +/- 0.20   0.622482934  0.196061022      0.043840577

NLL absolute error: 0.211059344; arithmetic relative error: 105.529672%.
RMSE absolute error: 0.122482934; relative error: 24.496587%.
Frozen tolerance: both means must be within the corresponding published
plus/minus band (0.26 NLL and 0.20 RMSE). Both pass this descriptive criterion.
This is not rounding agreement or a formal statistical equivalence test.
Relative changes in NLL are not invariant to target units; the absolute NLL
gap and the explicit tolerance are more useful than its relative percentage.

Uncertainty caveat: Table 1's caption calls the error bars standard errors,
but the current author script reports np.std with ddof=0. The original bars'
type is unresolved. We do not silently relabel them as SD or CI. Local SD uses
ddof=1; SEM is SD/sqrt(20). The splits reuse the same 308 observations, so the
SEM is descriptive and is not population-level independent-sample uncertainty.
If the published bars are SD rather than SEM, a comparison of mean precision
would be stricter than the tolerance used here; a precise match is unproven.

PROTOCOL AND IMPLEMENTATION
UCI Yacht: 308 rows, six features, final-column residuary resistance target.
20 outer splits from RandomState(1), using the author script's permutation
rule: 277 development rows, 31 held-out test rows per split. Each development
set is split into 221 training and 56 validation rows. Select the number of
stages by minimum validation NLL, then refit on all 277 development rows.
Gaussian NGBoost, log score, natural gradient, depth-3 regression trees,
minimum leaf size 1, learning rate 0.01, full minibatches, 2,000-stage cap.
Raw features and target units; no monthly-return scaling, clipping or row cap.
Primary chosen stages range from 353 to 487; no primary fit hits the cap.
Inner split seeds: 10000+split; tuning seeds: 20000+split; refit: 30000+split.
These seeds are local explicit choices, not recovered paper-run seeds.

Training calls scripts/models.py:NGB.paper_benchmark and its shared fit/predict
methods. The 2,000-stage ceiling comes from the current author Yacht launcher;
the paper does not specify the ceiling. The installed runtime is modern:
Python 3.11.16, NGBoost 0.5.11, scikit-learn 1.9.1, NumPy 2.4.6, SciPy 1.17.1.
This is fresh training, not replay of published predictions. The monthly
defaults retain their original depth-2/minimum-leaf-100/learning-rate-0.03
configuration, target scaling and variance clipping.

PRESERVED PROTOCOL DISCREPANCY / FAILED DIAGNOSTIC
The checked author script selects stages with argmin(val_rmse), although
Section 4 specifies validation log-likelihood. Before fitting, we declared
an MSE-selection diagnostic on exactly the same trained paths and test sets.
Its NLL is 1.951416781 +/- 2.361532336 split SD versus paper 0.20 +/- 0.26:
absolute gap 1.751416781, outside the frozen 0.26 tolerance. RMSE is
0.611005447 +/- 0.225330579 split SD versus 0.50 +/- 0.20. Nine of these
diagnostic selections hit 2,000 stages. This diagnostic is not an exact replay
of the original runtime or proof of a flaw in the paper; it demonstrates that
the documented selection difference materially affects this local result.
Neither the mismatch nor the primary mean gaps should be hidden by grade 2.
