Published baseline protocol
The archived author runner is official-code/baselines/run_pyod_baselines.py,
recorded commit cba2969e390ae6cd4381fe86393fa6cfcfc40d13. It fits PyOD LOF with
n_neighbors=20 on the labeled feature subset. The completed local baseline used
the corresponding sklearn LocalOutlierFactor implementation and its native score
-negative_outlier_factor_. Features are the author loader's float32 values cast
to float64, with no additional scaling. Elliptic has 166 features; Elliptic++
has 182. Both use 4,545 illicit and 42,019 licit transactions; 157,205 unknown
labels are excluded from this feature-only baseline's fit and evaluation.
No class values enter model fitting, no sign reversal is selected using labels,
and no test tuning was performed. This is a static transductive benchmark, not
a chronological stock-price forecast. Below-chance AUROC is the native result.
The original Elliptic feature set was reconstructed by the authors' conversion
script from Elliptic++; this provenance is retained rather than claiming an
independent Kaggle download.
